# Claude Code 原生路由与聚合验证

日期：2026-10-16 首验，2026-10-19 复验。范围：M2；macOS arm64，Claude Code 2.1.301 与 2.1.303。

## 交付范围

- Claude 工作空间独立的 IPv4 loopback 监听、随机本地令牌和持有期间的文件锁。
- 单连接路由与多连接聚合；稳定公开模型 ID、默认连接、默认模型及角色映射。
- 先预览再应用。运行中更新发布快照，在途请求继续使用开始时的连接、模型和凭据。
- JSON 和 SSE 原生转发，版本与 beta 请求头、查询参数、工具和 Thinking 字段保留。按[官方网关协议](https://code.claude.com/docs/en/llm-gateway-protocol)处理 Messages、模型目录与可选 token 计数。
- 流式观察覆盖内容块、工具参数增量、缓存用量及结束事件；只有收到完整结束序列才标记完成，符合[原生事件顺序](https://platform.claude.com/docs/en/build-with-claude/streaming)。
- 先恢复配置再停止监听。冲突保留服务与凭据；退出处理本实例的运行中路由。中断后保留恢复记录，下次启动不自动开启旧路由。
- 路由页、最近请求、MCP 控制与托盘入口；请求与用量按客户端和工作空间区分。
- CLI 收到独立消息 ID，本地日志与路由计数据此去重；不保存请求或响应正文。

当前支持 Anthropic Messages 上游。协议转换、云平台认证、官方多账号转接及自动备用队列在后续阶段实现。已有连接的编辑和删除仍需先恢复；默认连接、默认模型与模式可以在运行中预览更新。

## 真实 CLI 与模拟上游

使用 `examples/claude_route_probe.rs` 创建专用绝对目录，通过实际应用服务保存两个同名模型连接、发布聚合配置，并启动 Claude Code。首验使用 2.1.301；复验将已安装的 2.1.303 复制到探针目录，版本检查与两次请求均使用这份副本，不与正在运行的用户会话共用可执行文件。

发起路由请求的 CLI 进程采用 macOS `sandbox-exec`：只允许 loopback 出站网络；正常 Claude 用户配置和用户钥匙串目录不可读；写入限制在探针目录和临时目录。保留原 HOME 值，使用独立 `CLAUDE_CONFIG_DIR`，清理继承的认证与代理环境。版本检查使用复制出的 CLI 和独立配置目录。两个模拟上游分别要求 API Key 和 Bearer，验证认证头没有混用。

| 步骤 | 观察结果 |
| --- | --- |
| 默认连接 A | CLI 经 SwitchX 返回 `SWITCHX_M2_A` |
| 发布默认连接 B | 同一工作空间沿用端口，新 CLI 请求返回 `SWITCHX_M2_B` |
| 凭据 helper | 实际 SwitchX 二进制从隔离数据库读取本地令牌，CLI 成功访问路由 |
| CLI 日志 | 产生 2 个日志文件 |
| 路由用量 | 2 条记录 |
| 导入 CLI 日志后 | 仍为 2 条记录，没有重复统计 |
| 收尾 | 配置恢复完成，本地路由停止 |

这验证了真实 CLI、配置写入、helper、本地路由和日志导入之间的链路。上游全部为本机合成服务，没有真实账户或付费请求，也不代表某个真实模型的图片、工具或 Thinking 能力已通过验收。

### 复现

先构建当前 SwitchX 二进制，再使用一个尚不存在的专用绝对目录：

```sh
cargo build --locked --bin switchx
cargo run --locked --example claude_route_probe -- /absolute/new/probe-directory
```

此探针的网络隔离实现限 macOS。输出只包含验证结论和计数，CLI 原始诊断不会打印，以免客户端回显凭据。失败也会尝试恢复配置；原始资料保留在专用目录中供检查。

## 自动化覆盖

| 检查 | 覆盖 |
| --- | --- |
| 显式选路 | 两个连接使用相同实际模型名，公开 ID 和实际目的地保持独立；未知 ID 不走默认连接 |
| 协议与认证 | 版本、未知 beta 值及查询参数保留；API Key 与 Bearer 分别构造；客户端认证和 Cookie 不透传 |
| 流式语义 | 分片 UTF-8、CRLF、工具参数增量、多个内容事件、缓存和最终用量、错误及缺失结束事件 |
| 发布快照 | 修改默认连接和聚合模式时，已开始的流继续使用原目的地 |
| 并行运行 | 两个 Claude 工作空间与 Codex 同时运行，停止一个后其余保持可用 |
| 恢复与所有权 | 外部字段冲突、显式保留外部值、退出冲突、第二实例争用、强制终止后的恢复 |
| 去重与迁移 | 版本 19 连接资料与密钥保留；模型身份稳定；历史 Claude 日志响应 ID 迁移；路由和日志去重 |
| 本地边界 | Host 和 Origin 检查、独立令牌、凭据查询参数拒绝、16 MiB 请求上限、8 个并发转发上限 |
| UI 与 MCP | 工作空间与模式参数、一次性预览、模型去向、运行和恢复状态、双主题与紧凑窗口 |
