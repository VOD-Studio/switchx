# M3 官方订阅配置编辑

2026-09-29，macOS arm64、Slint 1.18.1。按用户提供的 CC Switch 截图补齐官方订阅编辑；实现参考 `others/cc-switch` 的 `CodexConfigSections.tsx`、`useCodexConfigState.ts` 和供应商保存流程。当前参考源码已移除通用配置入口，本次保留 SwitchX 已有入口以对应截图。

## 实现与边界

- 订阅编辑页可选择跟随目标 Codex 登录或保存账号，查看、修改及格式化 `auth.json`，直接编辑 `config.toml`。取消或切页清空凭据编辑内容；异步加载结果不会重新填回已关闭的编辑器。
- 原样保存 Native 登录 JSON 保留 Native 绑定；修改后保存为私有账号并绑定该账号，不改写目标 Codex 登录。修改保存账号须保留用户与工作区身份；编辑期间的登录或 token 轮换冲突会拒绝旧草稿。
- 1M 开关、阈值与 TOML 双向同步。关闭 1M 删除窗口与阈值；直接填写非 1M 窗口也可保存。普通共享字段在保存时剥离相同的继承值，后续继续读取最新通用配置；手动覆盖和上下文控件由连接保留。
- 非敏感 MCP 设置可保存在订阅 TOML，但不进入通用片段。凭据与供应商路由字段不允许写入订阅 TOML；官方地址、认证和公开模型映射由 SwitchX 管理。
- 编辑保存不应用原生登录或路由配置。下次开启路由使用默认模型所属连接的设置；恢复仍采用现有受管差异比较。完整 OAuth 快照只存于私有 `codex_oauth_auth.json`，兼容没有快照的旧账号。
