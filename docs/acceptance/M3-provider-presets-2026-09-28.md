# M3 官方 API 预设验收

2026-09-28，macOS arm64、Slint 1.18.1，使用本机调试 bundle、隔离的 `SWITCHX_DATA_DIR` 和 `CODEX_HOME`。测试 Key 为本轮生成的合成字符串，没有向真实模型接口发送请求。

## 实现

参照 `others/cc-switch/src/config/codexProviderPresets.ts`，添加 DeepSeek、Kimi、MiniMax 和小米 MiMo 四个原生 Responses 官方连接预设。选择预设填入名称、API 地址、默认模型，提供官网和获取 Key 的入口；用户可修改字段。地址与默认模型按 README 中列出的四家官方接入指南核对。

预设是静态连接默认值，保存、系统凭据、模型探测和独立映射复用现有流程。没有新增依赖或数据库迁移。模型能力仍由用户独立填写或导入，保存连接后通过已有的预览和应用流程启用。

SVG 来自 CC Switch 的 `src/icons/extracted/`，保留路径和原颜色；Kimi、MiMo 随主题着色。MiMo 调整画布留白与显示宽度以适配文字标识。来源和 MIT 许可位于 `assets/providers/NOTICE.md`，macOS bundle 同时包含该许可文件。

| 检查 | 结果 |
| --- | --- |
| 自动检查 | `make check` 通过：47 个库测试、2 个主程序测试、6 个路由集成测试，共 55 项；Rust/Slint 格式与 Clippy `-D warnings` 通过 |
| 预设数据 | 检查唯一 ID、有效地址/模型和 HTTPS 官网链接；官方品牌仅按准确端点匹配，支持尾斜杠及 DeepSeek `/v1`，自定义、伪造主机或含凭据的地址不显示官方标识 |

| 原生预填 | 四个按钮分别填入正确名称、地址和默认模型；自定义入口保持可用 |
| 预设切换 | DeepSeek 填入合成 Key 后切至 Kimi，Key 清空；MiMo 填入合成 Key 后回到自定义，名称、地址、模型与 Key 均清空 |
| 保存和编辑 | DeepSeek 保存后显示品牌图标；重新编辑保留地址/模型，Key 显示留空保留提示。系统凭据检查返回可读取；数据库仅含凭据引用，不含合成 Key 明文 |
| 字段可编辑 | 最终构建将 MiMo 名称改为 `MiMo UI Test` 后保存，重新编辑仍显示官方图标和正确地址/模型；留空 Key 再次保存后凭据仍可读取 |
| 自定义地址 | 编辑官方连接的 API 地址后，官方标识与链接消失；取消后已保存资料保留 |
| 官网入口 | DeepSeek 官方网站按钮打开系统浏览器，浏览器标签位于 `platform.deepseek.com` |
| 主题 | 最终构建查看深浅主题；四个按钮标识、MiMo 文字标识和表单内容可见 |

原生测试连接均通过两次点击确认删除，系统凭据清理成功；隔离配置全文哈希保持一致，未生成配置切换 journal。调试程序正常退出。

## 范围

本轮验证预设表单、品牌展示、已有保存流程与本地凭据操作，没有验证各家实际模型请求或账号目录；预设不代表已连通。真实连通性仍由用户自己的 Key 和“获取模型列表”检查，Responses 工具对话继续使用既有真实验收流程。浏览器获取 Key 页面未创建或修改账号凭据。Windows/Linux 尚未作原生界面验收。

复跑：`make check`，然后 `sh scripts/bundle-macos.sh`；启动应用时使用绝对路径的测试数据目录与临时 Codex 配置目录，在“上游供应商 → 添加上游”选择预设。
