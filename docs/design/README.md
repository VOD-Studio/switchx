# SwitchX 视觉方案预览

这是 **Quiet Circuit / 静谧回路** 方向的可点击设计稿，用来评审布局、色彩、信息层次和过渡节奏。正式应用仍采用 Rust + Slint；本设计稿不是产品实现，也不是实际 Codex 界面。

## 打开

在仓库根目录执行：

```sh
open docs/design/switchx-preview.html
```

非 macOS 系统直接使用浏览器打开该文件。无需安装依赖、网络连接或启动服务。

## 可以体验

- 右上角切换深色/浅色主题。
- 切换“直连 / 路由”，观察信息和操作范围变化。
- 在模型菜单选择上游，观察路由去向。
- 点击“演示一次请求”，观察有限的路径动画与请求记录。
- 点击上游卡片/添加上游，查看侧边抽屉；按 Escape 关闭。
- 切换导航，预览设置、工具与恢复的信息组织。
- 通过浏览器/系统的减少动态效果设置检查低动态模式。

全部连接状态和请求都是演示；不读取凭据、不连接模型、不修改 Codex。OpenAI Coding 是显示名示例，不代表某个固定的官方模型 ID。工具、恢复和设置页仅展示信息架构，不是完整编辑器。
